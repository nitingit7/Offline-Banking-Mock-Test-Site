# Practice Desk

## Start practising on Windows

Extract the ZIP, then double-click **Start Practice Desk.cmd**. The launcher uses Python 3 and opens the dashboard in your browser. Keep the launcher window open during a test. Each launch uses the same local address so your saved attempts are available there.

## Publish on GitHub Pages

1. Create a GitHub repository and commit the extracted files. Keep `docs/index.html` and the folders under `docs` together. GitHub Desktop can commit the complete folder in one operation.
2. In the repository, open **Settings → Pages**. Under **Build and deployment**, select **Deploy from a branch**.
3. Choose the branch containing the files (usually **main**) and the **/docs** folder. Click **Save**.
4. Once GitHub finishes deploying, open **Visit site** from the Pages settings. Visitors can practise without an account. The site works under a repository subpath.

The downloadable site contains its question bank. Publishing the site shares the bundled questions and answer keys with visitors. Your attempts stay in your browser.

[GitHub Pages publishing instructions](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)

## Practice and review

- **Speed drill** starts with the five speed-maths topics selected. Adjust the topics, number of questions and timer. Expand Arithmetic, English or Reasoning to include additional topics. Each selected topic appears in the drill.
- **Sectional mock** lets you choose the section, question count and duration.
- **Full mock** offers a three-section 100-question practice format and an 80-question RRB PO-style format. Sections have individual timers.
- **Previous papers** contains source-keyed memory-based RRB PO papers. The paper details show its date, question count and timing.
- **Attempt history** includes scorecards and question-by-question review. You can reattempt a test or focus on wrong and skipped questions.
- **My progress** compares net scores, accuracy and pace. Filter by test and mode for like-for-like comparisons. A percentage-point change uses the most recent two comparable results.
- **Move your history** in Attempt history saves a restorable file of completed attempts. Download a backup before moving from the local site to GitHub Pages, switching browsers or clearing site data. Restore from the same edition of the question bank. CSV export is also available.

## Question sources and scoring

Quantitative practice comes from the supplied MEGA PDFs. The English and reasoning bank combines verified uploaded sample questions with original Practice Desk questions. Source labels appear during answer review. Previous-year papers preserve the supplied publisher's question order and answer key. Timer and marking details appear before each test. Generated tests use +1 for a correct answer, −0.25 for a wrong answer and zero for an unanswered question.

## Included bank and verification

The practice library has 1,224 questions across 34 topics. Its 423 speed-maths questions cover simplification, approximation, missing number series, wrong number series and quadratic comparisons. Nine complete memory-based RRB PO papers contribute a further 720 question slots.

The printed answer letter for each of the 720 paper questions was independently checked against the supplied PDF. The accompanying CSV identifies the paper, question number, PDF key page and matching answer. The scored papers cover 2017, 2018, 2019, 2021, 2023, 2024 and 2025. Files without a reliable matching key were left out of the scored catalog.

Five question reviews explain an ambiguity or inconsistency in a source paper. These concern Q40 in 2019, Q30 on 4 August 2024, Q11 on 22 November 2025, Q68 on 23 November 2025 and Q50 in 2017. PYP results use the supplied key. The speed-maths answers were checked by calculation or by checking the stated series pattern. The other source checks establish agreement with supplied material and worked answers.
